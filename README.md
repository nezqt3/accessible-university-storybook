# Доступный вуз

**«Доступный вуз»** — цифровая платформа, объединяющая ключевые университетские
сервисы в одном интерфейсе. Продукт помогает студентам быстро получать нужную
информацию и переходить к привычным сценариям без поиска по разрозненным
системам.

## О продукте

Университетская цифровая среда обычно состоит из множества отдельных сервисов.
«Доступный вуз» объединяет их в единую точку входа и делает взаимодействие с
университетом проще и понятнее.

Платформа развивается вокруг нескольких принципов:

- **единый пользовательский опыт** — сервисы выглядят и работают согласованно;
- **быстрый доступ к важному** — расписание, профиль, уведомления, студенческие
  сервисы и навигация собраны в одном интерфейсе;
- **доступность** — сценарии проектируются с учётом удобства разных групп
  пользователей;
- **масштабируемость** — архитектура рассчитана на развитие продукта и
  подключение новых университетских сервисов.

## Публичная frontend-документация

Основной код платформы не публикуется. Этот репозиторий открыт как техническая
витрина подхода к frontend-разработке «Доступного вуза».

Storybook содержит интерактивные примеры shared-компонентов, их состояния,
варианты и рекомендации по применению:

| Направление          | Компоненты                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------------------- |
| Действия и навигация | Button, IconButton, BackButton, CloseButton, Pressable, Pagination                                 |
| Формы и ввод         | Input, Select, Textarea, Checkbox, Switch, FormField, OtpInput, DatePickerModal                    |
| Статусы и загрузка   | Alert, Badge, NotificationStatus, InlineSpinner, Spinner, Loader, Skeleton, EmptyState, ErrorState |
| Композиция           | Card, Modal, ModalHeader, TicketCodeModal, Container, Section, Typography                          |

В верхней панели Storybook можно переключать светлую и тёмную темы, цветовую
палитру, режим контрастности и масштаб текста.
